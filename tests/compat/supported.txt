# An iteration that makes akit read a field (and act on it: a field read and then ignored fails
# the gate) adds its path here in the same commit, then reruns python3 tools/compat-inventory.py,
# which checks every path is one fit accepts and regenerates docs/compatibility.md.
# The gate's tests check that akit-config reads each field listed here (supported_fields_are_read)
# and that these are exactly the fields its model reads (akit_config_lists_match_the_inventory).
